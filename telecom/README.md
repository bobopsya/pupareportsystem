# Бобтелеком

Игровой оператор связи экосистемы: вход и оплата через Bobobank («Войти через Bobobank», привязка счёта).

- **Номер**: обычный бесплатно или красивый (500–5 000 ₽, на «Премиуме» — со скидкой 50%), поиск по цифрам в конце.
- **Тарифы** Мини / Базовый / Безлимит / Премиум (меняются в админке). Смена тарифа сразу (новый период, полная цена) или со следующего периода.
- **Абонплата** каждые `BILLING_PERIOD_DAYS` дней (30 по умолчанию) — списание по привязке с `external_id = sub_<номер>_<период>`, повтор не списывает дважды. Нет денег — номер блокируется, повтор раз в час или кнопкой «Оплатить»; банк недоступен — повтор через минуту без блокировки.
- **Связь** только между абонентами Бобтелекома: SMS-чаты и звонки в приложении (входящий звонок, ответ, таймер; звука нет). Платит звонящий — по начатой минуте; без ответа 30 с — пропущенный.
- **Интернет** расходуется понемногу сам (симуляция), при остатке < 512 МБ приходит SMS.
- **Привязки.** Номер сам сообщается в Bobobank (переводы по +123 приходят на счёт, номер виден в профиле банка) и, после «Подтвердить через Бобуслуги», — на Бобуслуги: номер оформляется на Бобопаспорт и появляется в кабинете гражданина. Для Бобуслуг нужна миграция `bobuslugi/supabase/migrations/20261017000001_telecom.sql` и переменные `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `GOS_PUBLIC_URL` (те же, что у банка).
- Детализация с PDF-чеками, eSIM (QR для коллекции), админка: обзор, блокировка номеров, тарифы.

## Запуск локально

```
cd telecom/server && npm ci && npm run build
DATA_DIR=./data COOKIE_SECURE=0 WEB_DIST=../web/dist PORT=8085 \
BANK_INTERNAL_URL=http://127.0.0.1:8082 BANK_PUBLIC_URL=http://localhost:8082 BANK_TELECOM_SECRET=<секрет> node dist/index.js
```

Банк запускается с `TELECOM_PUBLIC_URL=http://localhost:8085 BANK_TELECOM_SECRET=<тот же секрет>`.

Админ: войдите на сайт, затем `docker compose exec telecom node dist/cli.js make-admin "Имя"`.
